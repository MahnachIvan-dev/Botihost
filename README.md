# BotHost v11 — Stable

Telegram-хостинг Python-ботов + отдельный AI Cashier.

### Что изменено

- исправлены гонки `start/stop/restart`;
- исправлен `KeyError` в `running_bots`;
- SQLite WAL + busy timeout + retry;
- автоматическая выдача слотов через подписанный канал;
- `APPROVED/REJECTED` события от кассира;
- защита от повторной выдачи по `grant_id`;
- пользовательские переменные без `.env` файлов;
- отдельное `.venv` на каждый пользовательский проект;
- автоустановка `requirements*.txt`;
- автоустановка распространённых отсутствующих Python-пакетов;
- авто-рестарт пользовательских ботов;
- AI-дебаггер логов;
- безопасная распаковка ZIP;
- Cashier с двумя изображениями для проверки;
- допуск времени проверки — до 10 минут;
- модель Cashier по умолчанию: `qwen/qwen3.8-27b`;
- более компактное и понятное меню BotHost.

Подробный деплой: `DEPLOYMENT.md`.
