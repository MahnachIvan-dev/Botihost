# BotHost v9.0

Стабильная сборка хостинга Telegram-ботов.

### Что исправлено
- SQLite: WAL + busy timeout + повторные попытки при `database is locked`.
- Атомарная выдача слота по `grant_id`, повторная оплата не выдаёт второй слот.
- Исправлена таблица `auto_grants`, которая требовалась для sync-выдачи.
- Кассир больше не использует общую SQLite-базу Host.
- Исправлен `grant_id` в кассире.
- Секреты Host не передаются пользовательским ботам.
- Пользовательские боты получают собственный `.env` и зависимости через отдельный venv.
- ZIP распаковывается безопасно.
- Один polling-процесс на каждый Telegram token.
- Авто-рестарт пользовательских ботов.
- Бэкапы основной БД.

Для запуска смотри `DEPLOYMENT.md`.
