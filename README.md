# BotHost v9.9 — Защищённая сборка с ограничением нагрузки

Telegram-хостинг Python-ботов + AI Cashier с дополнительной проверкой оплаты владельцем.

Версия 9.8 включает защиту от небезопасных ZIP, общие квоты хранилища, ограничение логов и восстановление состояния заморозок оплаты после перезапуска.

### Что изменено

- исправлены гонки `start/stop/restart`;
- исправлен `KeyError` в `running_bots`;
- SQLite WAL + busy timeout + retry;
- автоматическая выдача слотов через подписанный канал;
- `APPROVED/REJECTED` события от кассира;
- защита от повторной выдачи по `grant_id`;
- пользовательские переменные без `.env` файлов;
- отдельное `.venv` на каждый пользовательский проект;
- автоустановка `requirements*.txt`;
- автоустановка распространённых отсутствующих Python-пакетов;
- авто-рестарт пользовательских ботов;
- AI-дебаггер логов;
- безопасная распаковка ZIP: защита от ZIP-бомб, traversal, ссылок и частичной записи;
- лимит отдельного файла 20 МБ, проекта 100 МБ и общего хранилища;
- лимит свободного места, сериализация архивации и ограничение параллельных запусков;
- ограничение логов и пауза авто-рестарта после повторных падений;
- дополнительная проверка оплаты владельцем после одобрения кассиром;
- автоматическая временная заморозка пользовательских ботов при подтверждённой неоплате;
- ограничение размера скриншотов и числа параллельных AI-проверок;
- Cashier с двумя изображениями для проверки;
- допуск времени проверки — до 10 минут;
- модель Cashier по умолчанию: `qwen/qwen3.8-27b`;
- более компактное и понятное меню BotHost.

Подробный деплой: `DEPLOYMENT.md`.
