# BotHost — автоматические зависимости

Эта версия обновляет запуск пользовательских ботов:

- каждый пользовательский бот получает собственный `.venv`;
- автоматически устанавливаются все найденные `requirements.txt`, `requirements-*.txt` и другие файлы с `requirements` в имени;
- зависимости кешируются по SHA-256, поэтому при обычном перезапуске повторная установка не выполняется;
- если `requirements.txt` отсутствует и бот падает с `ModuleNotFoundError`, Host пытается установить отсутствующий пакет автоматически;
- `.env` конкретного бота загружается при запуске и может содержать несколько переменных `KEY=VALUE`;
- секреты самого BotHost не передаются пользовательским ботам автоматически;
- старые боты получают новый `wrapper.py` автоматически при следующем запуске;
- AI-анализ логов ограничен `max_tokens=400`, чтобы не получать ошибку Groq OTPM 429.

Для бота, которому нужен, например, OpenAI, положи в его проект:

```text
requirements.txt
openai
```

или создай `.env` через меню Host:

```env
OPENAI_API_KEY=...
```

Для нескольких зависимостей просто перечисли их строками в `requirements.txt`.
